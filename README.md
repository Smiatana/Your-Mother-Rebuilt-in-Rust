### You can now rebuild your mother in Rust!
Just launch the app, upload an image of your mother and generate an optimized piece of code that will make your mother lighter and faster!

## Build it yourself

1. Install [Node.js](https://nodejs.org/) and [Rust](https://rustup.rs/), plus the Tauri system dependencies for your OS.
2. Run `npm install` in the project directory.
3. Start the app with `npx tauri dev`, or create a release build with `npx tauri build`.
